# yaochengtong.github.io

Personal site, built with [Astro](https://astro.build/). Deployed to GitHub Pages by
`.github/workflows/deploy.yml` on every push to `main`.

## Write a post

1. Add `src/content/blog/<slug>.md` with frontmatter `title`, `description`, `pubDate` (`YYYY-MM-DD`).
2. Push to `main`. Done.

## Local dev (optional)

```sh
npm install
npm run dev
```

The old Hexo-generated site is preserved on the `master` branch.
